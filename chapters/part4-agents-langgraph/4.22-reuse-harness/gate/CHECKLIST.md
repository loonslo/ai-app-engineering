# L4.15 复用现成 harness · 实操清单

本章是清单章，没有可执行 gate。纸面比较必做，实操选做；所有证据填写到 [workbook](../workbook.md)，不把“未运行”写成通过。以下评分和门槛是课程实验规则，不是行业安全认证。

## 一、纸面审查

- [ ] 明确低风险、可撤销任务、输入输出与停止条件；写出领域长链路更适合 L4.11 执行面的理由。
- [ ] 从 README 六个候选中选两个，按同一九维比较，不因名称有 sandbox 就认为安全。
- [ ] 每个候选保存官方 URL、读取日期、版本证据，区分上游 main/滚动文档、历史发布、实际安装。
- [ ] 标明文件工具、Shell、插件、子进程、出网与会话日志各处于哪条边界内。
- [ ] 对文档未说明或不能核实的能力写未知，不用推测补齐版本、发布日期、隔离承诺或价格。
- [ ] 写复用/拒绝/暂缓理由及接入和退出成本。

## 二、实操启动前（任何一项不满足都不启动）

- [ ] 使用一次性工作区，整个 harness 在容器或 VM 中运行，而不只是部分文件工具在其中。
- [ ] 不放任何真实密钥、个人/生产数据；不透传宿主环境、HOME、SSH agent、云凭据或 Docker socket。
- [ ] 设置运行时出网规则，默认无网络；离线接入不需要真实凭据，外部遥测关闭。
- [ ] 锁定 SDK、插件、依赖锁、镜像 digest、沙箱后端；镜像准备与运行分离，运行时不下载 latest。
- [ ] 非 root、只读根、限制 CPU/内存/PID/墙钟，只挂载工作区，移除 capabilities，不用 privileged。
- [ ] 只做一个可撤销的低风险任务，固定合成输入，记录初始散列；金丝雀放在未挂载的宿主目录。
- [ ] 已定义宿主取消方式、输出审查、日志脱敏与销毁方式；无法维持边界就停止而不是放宽为任意权限。

## 三、实操九维取证

打分：0＝未知/缺失/探针失败；1＝有锁定版本文档及配置，未实测；2＝另有本次正反例证据。下列每项都要填写分数和证据，不是仅勾选“有功能”。

| 维度 | 必须观察的行为 | 分数 / 证据 |
|---|---|---|
| 文件隔离（硬项） | 正常读输入、只在允许目录输出；`..` / 宿主金丝雀不可见或拒绝，输入及金丝雀不变 | 待填写 |
| 网络隔离（硬项） | 非白名单 HTTPS 被运行环境阻断；有允许路径时补正例，不能只看配置文字 | 待填写 |
| 进程与资源（硬项） | 实际非 root、只读根、有限资源和进程范围；根目录写入失败、可取消短等待且无残留，不做资源耗尽攻击 | 待填写 |
| 权限与审批（硬项） | 禁止写入不进入 handler；审批拒绝在执行前生效；无内建审批时记录外层禁用策略，不冒充已验证审批功能 | 待填写 |
| 版本与供应链 | 断网使用固定镜像启动，版本与锁一致，无自动安装和未审查插件 | 待填写 |
| 会话与可观测性 | 可还原工具、参数摘要、结果、错误与停止；记录日志位置、合成敏感标记、遥测关闭与删除/保留结果 | 待填写 |
| 模型兼容 | 所选无密钥离线路径真的完成工具消息和最终回答；列出不支持项，不外推所有供应商 | 待填写 |
| token 与成本 | 预算缩小有界停止；请求数/token 有证据，不可测 usage 写不可测，不填真实费用 0 | 待填写 |
| 失败处理 | 缺失合成输入有可读失败、可取消；宣称可恢复则提供重开与不重复副作用证据，否则标未验证 | 待填写 |

- [ ] 任何宿主越界、非允许出网或未授权 handler 执行都立即停止，并记录已发生影响。
- [ ] 人工审查输出、差异、日志和实际停止条件，不把 Agent 的自述当探针结果。
- [ ] 按量表打分写入 workbook；无来源/未做项不填 2 分。

## 四、撤销与交付

- [ ] 只导出审查后的产物及脱敏证据，没有把完整含敏感信息会话直接分享。
- [ ] 停止并销毁一次性容器/VM；核对外部金丝雀与输入散列、没有残留任务。
- [ ] 记录选定方案、拒绝理由、退出时需要迁移的会话/文件/插件与必须重验的契约。
- [ ] 把真实模型、云后端、生产安全、持久执行与未实测候选列为未验证。

## 通过标准

- **纸面路径**：两个候选九维齐全，有一手来源、未知项、选择/拒绝/暂缓和退出成本；注明“未实操”，不套用实验通过称号。
- **选做实操路径**：启动前全部满足，九维至少 14/18，文件/网络/进程/权限四项各为 2 分；没有越界、非允许出网或未授权执行；证据、撤销和未验证边界完整。
- 硬项失败不能用总分抵消；缺少允许的无密钥离线路径时不运行是正确的边界决定，不等于实操通过。
