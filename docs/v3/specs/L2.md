6. 常见失败：上下文污染、无关内容分散注意力、指令互相冲突。

### 闭卷接口（`gate/starter.py`）

```python
class ContextBudgetError(ValueError): ...

@dataclass(frozen=True)
class Section:
    name: str
    text: str
    kind: str          # "static" | "dynamic"
    priority: int      # 越大越优先
    required: bool = False

@dataclass(frozen=True)
class AssembledContext:
    text: str
    included: tuple[str, ...]
    dropped: tuple[str, ...]
    tokens: int
    static_prefix_hash: str
    warnings: tuple[str, ...]

def count_tokens(text: str) -> int:
    """近似计数：每个 CJK 字符记 1；其余部分按空白切分，每个非空片段记 1。gate 只用这个函数，保证结果确定。"""
def assemble_context(sections: list[Section], budget: int) -> AssembledContext:
    """- 输出顺序：先放全部被纳入的 static（按传入顺序），再放 dynamic（按传入顺序）；
    - required 全部纳入；仅 required 就超出 budget 时抛 ContextBudgetError；
    - 非 required 按 priority 从高到低尝试纳入，放不下的进入 dropped（同 priority 按传入顺序）；
    - name 或 text 重复的 section 只保留第一个，warnings 记 "duplicate:<name>"；
    - 各 section 之间用两个换行连接；tokens 为 count_tokens(text)；
    - static_prefix_hash = sha256(按顺序拼接的被纳入 static 文本)。"""
def lint_context(sections: list[Section], budget: int) -> list[str]:
    """- static section 的文本含日期或时间戳（如 2026-10-27、10:30:00）时，记 "volatile_in_static:<name>"；
    - 单个 section 超过 budget 的 50% 时，记 "oversized:<name>"。"""
```

### 检查项（总数 ≥10）

static 在前；required 保留；required 超预算报错；按 priority 丢弃；同 priority 时顺序稳定；重复 section 去重并告警；只改 dynamic 时 hash 不变；改 static 时 hash 改变；static 中含时间戳被 lint 发现；oversized 告警。

## L2.7 查询改写与 agentic retrieval · 换实现 + 增补

- **目录**：`chapters/part2-rag/2.9-query-rewrite/`；文件 `query_rewrite.py`
- **换实现**：原生改写（口语、多轮、缩写），用 openai SDK 实现。
- **gate 追加 ≥6 项**（按 [conventions.md 6.4](../conventions.md#64-给已有-gate-追加检查项) 处理）。在 `gate/starter.py` 末尾追加：

```python
@dataclass(frozen=True)
class Hit:
    source: str
    index: int
    score: float
    text: str

@dataclass(frozen=True)
class AgenticResult:
    hits: tuple[Hit, ...]           # 按 source#index 去重，按 score 降序
    rounds: int
    queries: tuple[str, ...]
    stopped_reason: str             # "enough" | "no_rewrite" | "max_rounds"

def agentic_retrieve(question: str, search_fn, rewrite_fn, *, max_rounds: int = 3, min_hits: int = 2) -> AgenticResult:
    """每轮用当前查询调用 search_fn(query) -> list[Hit]，结果累计去重；
    累计命中数 >= min_hits 时停止，原因 "enough"；
    rewrite_fn(question, hits_so_far) 返回 None 时停止，原因 "no_rewrite"；
    轮数达到 max_rounds 时停止，原因 "max_rounds"；max_rounds < 1 抛 ValueError。"""
```

新增检查：第 1 轮命中足够即停止；改写一次后命中足够；改写函数返回 None 时停止；达到最大轮数时停止；跨轮去重；最终按分数排序。

- **README 新增一节**“什么时候让 Agent 直接搜索”：代码库与高频变化的数据（日志、工单、CRM）适合用工具直接搜索；取舍是新鲜度对召回、成本与延迟。引用一份 2026 年生产 RAG 指南的成本延迟对比，并标明数字来自厂商博客、未经独立验证。

## L2.9 静态上下文与 Skills · 新增 · gate

- **目录**：`chapters/part2-rag/2.13-static-context-skills/`（新建）
- **课时**：4h
- **岗位任务 / 面试题型**：T3、T7 / F3
- **学完能做**：读懂并编写 `AGENTS.md` 与 SKILL.md；实现渐进披露的 Skill 加载；发现说明文件里的膨胀与疑似密钥。

### README 必讲

1. `AGENTS.md`、`CLAUDE.md` 的作用：给编码 Agent 的项目说明。
2. Agent Skills：一个 Skill 是一个文件夹，含 SKILL.md（YAML frontmatter 中的 name、description，加 Markdown 正文），以及可选的 scripts、references。2025-12-18 以开放标准发布于 agentskills.io（引用并注明读取日期）。
3. 渐进披露：启动时只加载 name 与 description；触发时才加载正文；参考文件按需读取。估算这样省下的 token。
4. 安全：Skill 可以带脚本，存在供应链风险；雷达 Vol.34 指出风险已从 MCP 延伸到 Skills。
5. 指令膨胀：说明文件越长，越容易互相冲突、被模型忽略。

### 闭卷接口（`gate/starter.py`）

- **目录**：`chapters/part2-rag/2.14-memory-compaction/`（新建）
- **课时**：4h
- **岗位任务 / 面试题型**：T3 / F3
- **学完能做**：在预算内压缩长会话而不丢关键事实；实现按用户隔离、受写入策略约束的长期记忆。

### README 必讲

1. 短期记忆（会话）与长期记忆（事实、偏好）的区别。
2. 压缩策略：截断、摘要、结构化笔记。
3. 压缩与缓存的取舍：压缩会改变前缀，导致缓存失效。
4. 记忆隔离：跨用户泄露就是安全事故；OWASP Agentic Top 10 的 ASI06（记忆与上下文投毒）。
5. 写入策略：什么值得记、何时需要用户确认、过期时间。
6. 怎样评测记忆：关键事实在 20 轮后是否还在。

### 闭卷接口（`gate/starter.py`）

```python
@dataclass(frozen=True)
class CompactResult:
    messages: list[dict]
    summarized_count: int
    prefix_changed: bool

def compact_history(messages: list[dict], budget: int, summarize_fn, *, keep_last: int = 4, count_tokens=...) -> CompactResult:
    """不超预算时原样返回，prefix_changed=False。超预算时：
    - 保留第一条 system 消息与最后 keep_last 条消息；
    - 带 "pinned": True 的消息永远原样保留，并保持原有相对顺序；
    - 其余中间消息交给 summarize_fn(list) -> str，压成一条 role="system"、以 "[摘要]" 开头的消息，放在第一条 system 之后；
    - summarize_fn 抛异常时改为直接截断，摘要写 "[摘要不可用，已截断 N 条]"；
    - prefix_changed 表示第一条 system 之后的内容是否发生了变化。"""

class MemoryStore:
    def remember(self, tenant_id: str, user_id: str, key: str, value: str, *, source: str, confirmed: bool) -> bool:
        """source ∈ {"user", "model"}；source="model" 且 confirmed=False 的写入被拒绝，返回 False。"""
    def recall(self, tenant_id: str, user_id: str, key: str) -> str | None: ...
    def forget(self, tenant_id: str, user_id: str, key: str) -> bool: ...
    def export(self, tenant_id: str, user_id: str) -> dict[str, str]: ...
```

### 检查项（总数 ≥10）

预算内原样返回；system 保留；最后 N 条保留；pinned 保留；摘要插入位置正确；摘要失败时退化为截断；压缩后不超预算；`prefix_changed` 判断正确；跨用户、跨租户不可读；未确认的模型写入被拒绝；`forget` 与 `export` 正确。
