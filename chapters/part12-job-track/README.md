# 篇 12 · 就业轨道（J）

[全书目录](../README.md) · [上一篇 篇 11](../part11-project-sprint/README.md)

第 3–16 周持续训练面试形式与求职材料，避免“学完才开始准备”。内容对应招聘流程的三道关：**筛选**（简历与作品）、**面试**（编码、AI 辅助编码、系统设计、take-home、评测讨论、行为面）、**投递管理**。

出口：课程大纲（[outline.md 第 6 节](../../docs/v3/outline.md#6-就业出口标准e1e4)）的 E3 面试准备与 E4 求职材料。

## 与 L0.5 岗位地图的衔接

[L0.5 岗位地图与差距诊断](../part0-setup/0.5-job-map-gap/README.md)是本篇的起点：它帮你选目标岗位、找出差距；本篇把差距变成每周可执行的训练和可投递的材料。目标岗位变了，回到 L0.5 重新诊断，再调整本篇各章的侧重。

## 证据怎么登记

面试准备的成果也要登记到 [L0.2](../part0-setup/0.2-learning-workflow/README.md) 的证据索引里：每一份系统设计复盘、每一次 take-home 的检查器输出与自评、每一次 AI 辅助编码的验证记录，都写一行“声明 → 证据文件或命令 → 日期 → 类型”。简历和故事里出现的事实，必须能在证据索引里找到来源。证据索引模板见 [11.6](../part11-project-sprint/11.6-project-narrative/templates/evidence-index.md)。

## 信息会过期

市场与面试形态的变化很快。本篇 README 里的事实都注明来源、读取日期和**性质**（研究、厂商、媒体报道、行业经验）；超过 6 个月的内容请自行复核。以招聘方当次发给你的通知为准。

## 底线

不在简历与面试中虚构经历或数字。模板里的示例文字一律是“待填写”，不是可以照抄的内容。
