本章为清单式 Gate。完成以下练习步骤并在 `workbook.md` 中记录过程与复核分析。

- [ ] 把 `practice_repo/` 复制到 `.tmp/practice/`，在副本上练习，不改仓库中的原件。
- [ ] 让编码 Agent 读 `TASK.md` 并给出计划；把计划摘要记进 `workbook.md`。
