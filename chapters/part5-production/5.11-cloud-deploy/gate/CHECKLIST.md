# L5.8 云部署 · 验收清单

本章是清单章，没有可执行 gate。证据写到 [workbook](../workbook.md) 与 [`templates/deploy-record.md`](../templates/deploy-record.md)。**需要自己的云账号或 VPS，可能产生费用**；没有做的项写“未运行”，不要勾选。

- [ ] 选定云与区域，写明理由（目标雇主常用、成本、合规）；
- [ ] 先设置预算告警，再部署；
- [ ] 部署容器并通过健康检查（`/health`、`/ready`）；
- [ ] 通过 HTTPS 访问，并确认 HTTP 不直接暴露业务接口；
- [ ] 密钥不在镜像或仓库中，用平台的密钥管理注入；
- [ ] 日志可以按 `trace_id` 找到一次请求；
- [ ] 写出回滚步骤并实际演练一次；
- [ ] 记录 URL（可以只记私有地址）、区域、日期、每日成本；
- [ ] 用完即删：列出创建过的资源，删除后确认没有残留与持续扣费。
