# SQLite 架构概览

SQLite 由核心引擎、编译器与后端存储构成。

## 组件与功能

| 组件 | 层次 | 核心职责 |
| :--- | :--- | :--- |
| SQL 编译器 | 前端 | 词法分析、语法解析与代码生成 |
| 虚拟机 VDBE | 中端 | 执行生成的字节码指令 |
| B-Tree 引擎 | 后端 | 组织与管理数据页与索引页 |
| 寻呼机 Pager | 底层 | 提供事务 ACID 保证与 WAL 日志机制 |
| OS 适配层 | 系统 | 跨平台文件锁与 I/O 操作封装 |

通过寻呼机，SQLite 支持事务的原子性与持久性。
WAL 模式下允许多个只读事务与一个读写事务并发执行。
