# 系统设计模拟题与追问清单

每次只看当次那一题的题面，**写完再看追问清单**。

## 题 1 · 带权限与引用的企业文档问答

**题面**：为一家 2000 人的公司设计内部文档问答系统。文档来自多个部门，有不同的访问权限；答案必须带引用；文档每天更新。

**追问清单**：

- 权限在哪一层强制？为什么不是“检索之后再过滤”？
- 文档更新后，旧答案和缓存怎么失效？
- 怎么证明某个用户没有看到不该看的内容？写出对应的测试。
- 怎么评测引用是否正确？golden set 从哪来？
- 日均 5 万次问答、每次约 3000 token，月成本大概多少？怎么降？
- 模型厂商限流时怎么降级？

## 题 2 · 通过 3 个内部工具帮用户提交工单的 Agent

**题面**：设计一个 Agent，通过 3 个内部工具（查订单、创建工单、关闭工单）帮用户提交工单。

**追问清单**：

- 哪些操作无需确认，哪些必须人工确认？依据是什么？
- 怎么防止 Agent 陷入循环或重复创建工单？
- 工具返回的内容里夹带指令（提示词注入）怎么办？
- 怎么测试这个 Agent？轨迹怎么评估？
- 同一个请求用户点了两次，会发生什么？
- 审批人很久不回应，任务怎么处理？

## 题 3 · 通话摘要的评测体系

**题面**：为一个“通话录音转写后自动生成摘要”的功能设计评测体系。

**追问清单**：

- golden set 里放什么？怎么保证覆盖真实分布与困难样本？
- 谁来标注？怎么处理标注者之间的不一致？
- 用 LLM 裁判时怎么校准？一致率多少算可用？
- 什么情况下阻止发布？门槛怎么定、谁来改？
- 线上怎么发现质量下降？
- 评测本身的成本怎么控制？

## 题 4 · 带成本控制与降级的多租户 LLM 网关

**题面**：设计一个多租户的 LLM 网关，统一接入多家模型厂商，要求成本可控、故障可降级。

**追问清单**：

- 租户的预算、限额怎么强制？超限时怎么办？
- 某家厂商限流或宕机时怎么降级？重试会不会放大问题？
- 缓存与路由怎么设计？哪些请求不能缓存？
- 怎么做到按租户的成本归因？
- 日志里怎么避免存下敏感内容？
- 怎么灰度发布一个新的路由策略并随时回滚？

## 题 5 · 异步长任务调研 Agent

**题面**：设计一个异步的调研 Agent：用户提交一个主题，系统花几分钟到几小时产出报告；中途可能需要人工审批；需要支持检查点。

**追问清单**：

- 控制面和执行面怎么分？状态存在哪里？
- worker 崩溃后怎么恢复？已经产生的副作用怎么避免重复？
- 审批、取消、超时分别怎么处理？
- 怎么给任务设预算（步数、token、时间）？
- 怎么评测一份报告的质量？
- 完成后怎么通知调用方？通知失败怎么办？
