# 0.2 学习方法 · 清单验收

本章是学习流程，不设 gate；用清单证明你会用课程结构。

## 步骤

- [ ] 从 `chapters/README.md` 找到当前 v2 阶段与前置。
- [ ] 选一章，写出：目标、前置、时间盒、验收命令、通过后对照。
- [ ] 跑一次 `pytest tools chapters/test_new_lessons.py -q`。
- [ ] 在 workbook 写一条“预测 → 运行 → 实际 → 差异”。
- [ ] 记录一次卡住时准备查的资料/实验，而不是直接看答案。
- [ ] 建好自己的作品仓库或作品目录。
- [ ] 建好证据索引文件并登记第一条记录。

## 证据

```text
选章：
v2 路径 / 前置：
验收命令与结果：
一条预测-验证记录：
作品目录 / 仓库路径：
证据索引首条记录（编号/名称/路径/类型/日期/结论）：
未验证：
```

## 通过标准

- 能独立找到前置与验收命令。
- 预测与结果分开写，失败有原因。
- 不把 README 读完当完成。
