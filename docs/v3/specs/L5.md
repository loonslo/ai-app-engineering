### 闭卷接口（`gate/starter.py`）

gate 用 `opentelemetry-sdk` 的 `InMemorySpanExporter` 收集 span。属性名以实施时的语义约定为准，在各函数 docstring 中逐个列出并注明版本。

```python
@dataclass(frozen=True)
class Usage:
    input_tokens: int
    output_tokens: int
    cached_input_tokens: int = 0

def llm_span(tracer, *, operation: str, model: str, provider: str):
    """上下文管理器；span 名为 f"{operation} {model}"；写入操作名、请求模型、provider 三个属性。"""
def tool_span(tracer, *, tool_name: str, call_id: str):
    """上下文管理器；写入工具名与调用 ID 属性。"""
def record_usage(span, usage: Usage) -> None:
    """写入输入、输出 token；缓存命中 token 有标准属性时用标准属性，否则用带项目前缀的自定义属性，并在 docstring 说明。"""
def record_error(span, exc: BaseException) -> None:
    """span 状态置为 ERROR，并记录异常事件；不写入任何 prompt 文本。"""
def maybe_capture_content(span, prompt: str, completion: str, *, capture: bool, redact) -> None:
    """capture 为假时什么都不写；为真时，先经 redact 脱敏再写入。"""
def inject_traceparent(headers: dict, trace_id: str, span_id: str, sampled: bool) -> dict:
    """写入 "traceparent": "00-<32 位十六进制 trace_id>-<16 位十六进制 span_id>-<01 或 00>"；ID 格式非法时抛 ValueError。"""
def extract_traceparent(headers: dict) -> tuple[str, str, bool] | None:
    """解析 traceparent；格式非法、ID 全为 0 或缺失时返回 None。"""
def summarize_trace(spans: list) -> dict:
    """返回总耗时（毫秒）、LLM span 数、工具 span 数、token 合计、出错 span 的名字列表。"""
```

### 检查项（总数 ≥10）

span 名称与属性；usage 属性；错误状态与异常事件；默认不采集正文；采集时先脱敏；traceparent 写入格式；解析合法头；非法头与全零 ID 返回 None；trace 汇总数值；嵌套的工具 span 的父子关系。

```python
def create_app(store, queue, *, approver_role: str = "approver") -> "FastAPI":
    """身份取自请求头 X-Tenant、X-Role（gate 的简化鉴权）。
    POST /tasks：必须带 Idempotency-Key 头，缺失返回 400；新任务返回 202 和 {"task_id"}；相同 key 返回同一个 task_id。
    GET /tasks/{id}：从 store 读状态；其他租户的任务返回 404。
    POST /tasks/{id}/cancel：置取消标志，返回当前状态。
    POST /tasks/{id}/approval：只有 approver_role 可以调用，否则返回 403；请求体为 {"stage", "decision"}。"""
def sign_payload(body: bytes, secret: bytes) -> str:
    """HMAC-SHA256 十六进制摘要。"""
def send_webhook(task: dict, url: str, secret: bytes, http_post, delivered: set[str], *, max_attempts: int = 3) -> bool:
    """请求头带 X-Signature；遇到 5xx 或连接错误时重试，最多 max_attempts 次；4xx 不重试；
    同一 task_id 只成功投递一次（delivered 去重）。http_post 由 gate 注入。"""
```

### 检查项（总数 ≥10；用 FastAPI `TestClient` 与内存 store / queue）

提交返回 202 与 task_id；提交幂等；缺少幂等键返回 400；跨租户查询返回 404；状态取自 store；取消生效；非审批角色返回 403；签名可以验证；5xx 时重试且有次数上限；4xx 不重试；重复投递被去重。

### 闭卷接口（`gate/starter.py`）

```python
@dataclass(frozen=True)
class RequestResult:
    latency_ms: int
    status: int            # HTTP 状态码；0 表示超时

def percentile(values: list[int], q: float) -> int:
    """最近秩法：先排序，取第 ceil(q * n) 个值（从 1 开始计数）；values 为空或 q 不在 (0, 1] 时抛 ValueError。"""
def summarize_load(results: list[RequestResult], duration_s: float) -> dict:
    """返回 p50、p95、p99、error_rate（status 为 0 或 >= 500 或 == 429 的占比）、rps、按类型计数（429、5xx、timeout）。"""
def check_slo(summary: dict, slo: dict) -> list[str]:
    """slo = {"p95_ms", "error_rate"}；返回未达标的项。"""
def error_budget(slo_target: float, total: int, failed: int) -> dict:
    """返回允许失败数 floor((1 - slo_target) * total)、已用比例、是否耗尽。"""
def plan_capacity(peak_rps: float, per_instance_rps: float, headroom: float, *, tokens_per_req: int, rpm_limit: int | None, tpm_limit: int | None) -> dict:
    """实例数 = ceil(peak_rps * (1 + headroom) / per_instance_rps)；
    同时判断按每分钟请求数与 token 数是否会撞上模型限额，返回 {"instances", "rpm_needed", "tpm_needed", "bottleneck"}，
    bottleneck ∈ {"none", "rpm", "tpm"}。"""
def restore_drill(results: dict) -> dict:
    """results 包含 backup_exists、restore_minutes、rto_minutes、data_loss_minutes、rpo_minutes、smoke_passed；
    返回 {"passed", "failed_items"}。"""
```

### 检查项（总数 ≥10）
