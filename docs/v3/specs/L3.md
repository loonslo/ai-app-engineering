## L3.6 回归、A/B、pass^k 与报告 · 换实现 + 增补

### 目录 1：`chapters/part3-evals/3.7-eval-regression-curve/`

- **换实现**：`regression_curve.py` 改用原生调用。
- **gate 追加 ≥5 项**（按 [conventions.md 6.4](../conventions.md#64-给已有-gate-追加检查项) 处理）。在 `gate/starter.py` 末尾追加：

```python
def pass_at_k(n: int, c: int, k: int) -> float:
    """n 次独立尝试中有 c 次成功时，“k 次里至少成功 1 次”的无偏估计：1 - C(n-c, k) / C(n, k)。
    k > n、c > n 或任一参数为负时抛 ValueError；n - c < k 时返回 1.0。"""
def pass_all_k(success_rate: float, k: int) -> float:
    """单次成功率为 p 时，连续 k 次全部成功的概率 p**k；p 不在 [0, 1] 或 k < 1 时抛 ValueError。"""
def empirical_pass_all(results: dict[str, list[bool]], k: int) -> float:
    """每个任务取前 k 次记录，统计“k 次全部通过”的任务占比；某任务记录不足 k 次时抛 ValueError。"""
def split_suites(results: dict[str, list[bool]], regression_floor: float = 0.95) -> tuple[list[str], list[str]]:
    """通过率 >= regression_floor 的任务归入回归集，其余归入能力集；两个列表都按任务名排序。"""
```

新增检查：`pass_at_k` 的已知数值（如 n=10、c=3、k=1 时为 0.3）；参数非法时报错；`pass_all_k(0.75, 3)` 约等于 0.4219；`empirical_pass_all` 的统计；`split_suites` 的划分与排序。

- **README 增补**：
  - 能力评测与回归评测的区别：能力评测起点低、留出提升空间；回归评测应接近 100%，任何下降都是退化信号。
  - pass@k 适合“成功一次就够”的场景；pass^k 适合面向客户、要求稳定的场景。
  - 两者都引用 Anthropic 指南，注明读取日期。
