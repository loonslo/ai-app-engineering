# v3 审核清单

审核者按本清单逐项验收；实施者提交前先按同一清单自检。规范细节见 [conventions.md](conventions.md)，章节要求见各批次细则。

## 1. 流程

1. 核对提交包（[README 第 5 节](README.md#5-提交审核的格式)）是否完整；缺项直接退回。
2. 亲自重跑 [conventions.md 第 11 节](conventions.md#11-验证命令) 的命令，不只看提交里的输出。
3. 逐章对照细则阅读 README、workbook、gate 与参考实现。
4. 写审核记录 `docs/v3/reviews/<批次>.md`，给出结论。

## 2. 结论与严重度

| 严重度 | 含义 | 例子 |
|---|---|---|
| 阻断 | 不修不能合并 | gate 骨架能通过、参考解不能全过；测试联网；事实错误；改了 v2 标签；目录被改名 |
| 主要 | 影响学习效果或一致性，需修改 | 细则要求的内容缺失；故障注入没有对应检查；README 与 gate 计数不一致 |
| 次要 | 不影响正确性 | 措辞、排版、个别链接文字 |

- **通过**：无阻断、无主要问题。
- **修改后通过**：无阻断；主要问题 ≤3 个且修改范围明确，修完由审核者复核对应条目。
- **退回**：有任一阻断项，或主要问题 >3 个。

## 3. 通用检查

### A. 提交包（阻断）

- [ ] 改动文件清单完整，与 `git status` 一致。
- [ ] 每个 gate 都有临时参考解，路径符合约定。
- [ ] 有验证记录 `docs/gate-v3-<批次号>-validation.md`，内容是实际运行结果。
- [ ] `TASKS.md`、`PROJECT_STATUS.md` 已按契约更新，`evidence` 路径真实存在。

### B. 结构与索引

- [ ] 新目录的编号、名称与 outline.md 一致；没有任何旧目录被改名（阻断）。
- [ ] `tools/course_catalog.py` 已登记新目录。
- [ ] 新章节 README 的 `v3 路径` 行与 `docs/course-v3-map.json` 一致。
- [ ] 导航链接按 v3 顺序；`python tools/check_course_links.py` 断链 0（阻断）。
- [ ] 没有修改 `chapters/README.md`、根目录 `README.md`（V3-10 除外）。

### C. gate 质量（阻断）

- [ ] 默认骨架 0 通过、退出码 1。
- [ ] 临时参考解全部通过、退出码 0；连跑两次输出一致。
- [ ] 检查项数量 ≥ 细则规定；README 故障注入表每一条都有对应检查。
- [ ] 不联网、不读 `.env`、不调用 `time.sleep`；模型、工具、时钟全用替身。
- [ ] `starter.py` 的 docstring 足以独立实现；不泄露答案。
- [ ] 追加检查项时，原有检查项的名字与顺序未变。

### D. 内容与细则一致（主要）

- [ ] 细则“README 必讲”的每一点都讲到，且讲清楚。
- [ ] 闭卷接口与细则一致（函数名、参数、返回结构、错误码）。
- [ ] README 的验收标准、提交物与 gate 实际检查一致。
- [ ] “边界”一节写明没验证什么、简化了什么。
- [ ] 时间盒合理：按细则课时能完成。

### E. 代码质量（主要）

- [ ] `ruff check --target-version py311` 通过。
- [ ] 不在 conventions.md 第 7 节以外的位置导入 LangChain / LangGraph（阻断）。
- [ ] 不写死模型 ID、密钥、base_url；模型调用经由 `common` 工厂。
- [ ] 参考实现缺少密钥时给出可读提示，不报堆栈。
- [ ] 类型标注齐全、函数短小；注释写原因与契约。

### F. 事实与时效

- [ ] 版本、价格、弃用等事实有官方链接与读取日期（缺失为主要，错误为阻断）。
- [ ] 没有使用已下线或过时的接口，如 OpenAI Assistants API、旧的 DeepSeek 模型别名。
- [ ] Pydantic AI、OpenTelemetry 等依赖的版本与 `requirements-course.txt` 一致。

### G. 就业对齐（主要）

- [ ] 头部写明岗位任务 T 与面试题型 F，内容确实服务于它们。
- [ ] 产物可以直接作为作品证据或面试素材（第 6 节 E1–E4）。

### H. 证据诚实（阻断）

- [ ] 验证记录区分离线 gate、真实模型运行与部署。
- [ ] 没有把“文件存在”“gate 通过”写成“已验收”或“已掌握”。

### I. 回归（阻断）

- [ ] `python -m pytest tools chapters/test_new_lessons.py chapters/test_v3_lessons.py -q` 通过。
- [ ] 本批次碰过的旧 gate，用原有的临时参考解重跑仍全部通过。
- [ ] `python tools/apply_v2_map.py --check` 显示无变化。

### J. 文风（次要，系统性问题升为主要）

- [ ] 第一句直接点题；没有套话。
- [ ] 第一次出现的术语有一句解释。
- [ ] 中文标点；术语保留英文。

## 4. 按章节类型追加的检查

| 类型 | 追加检查 |
|---|---|
| 换实现 | 本章目录 LangChain grep 为零（保留的对照文件除外）；参考实现保留原演示步骤与输出结构；gate 未改动 |
| 新增 gate 章 | 接口与细则一致；故障注入覆盖细则全部条目；参考实现能离线演示主流程 |
| 清单章 | `CHECKLIST.md` 的步骤可执行、证据模板可填写、通过标准可判断 |
| 项目章 / 就业章 | 模板完整且可直接复用；演练代码的测试在未修复时失败、修复后通过 |
| capstone 批次 | 34 项离线测试、`milestones --strict-evidence`、`project_baseline` 全过；`capstone/` 无 LCEL 导入；简历措辞与代码一致 |
| 索引批次 | `apply_v3_map.py --check` 幂等；章节总地图与 outline.md 一致；全仓库断链 0 |
