# 简历条目（模板）

> 条目公式：**动作 + 系统 + 数字 + 证据**。数字只取自证据索引；简历里不写代码不支持的说法。三类目标岗位各写一组，侧重点不同。

## 检查规则

- 每条数字后面在草稿里标证据编号（投递版可以去掉编号，但草稿要保留）；
- 数字不能比证据大，样本很小要写样本量；
- 仍有框架胶水时，不写“完全去框架”；没有真实用户，就不写“用户”。
