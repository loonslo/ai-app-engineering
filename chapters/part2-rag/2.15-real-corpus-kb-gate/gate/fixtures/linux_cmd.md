# Linux 常用文件检索与归档指令

find 命令用于在目录层级中检索指定文件：
常用选项包括 `-name` 指定名称匹配模式，`-type f` 指定普通文件类型，`-size` 按文件大小筛选。

tar 命令用于归档与压缩操作：
常用选项组合 `-czvf` 用于创建 gzip 压缩归档包（c 为创建，z 为 gzip，v 为详细输出，f 为目标文件）。
常用选项组合 `-xzvf` 用于解压并还原 gzip 压缩归档文件（x 为解包提取）。

# Linux 文本流分析与处理指令

grep 命令用于在文件或输入流中按正则表达式进行模式匹配：
常用参数 `-v` 用于反向匹配（invert match），仅输出不符合匹配模式的文本行。
常用参数 `-i` 忽略大小写，`-n` 输出匹配行所在的文件行号。

awk 命令是强大的文本格式化与结构化报表处理工具：
默认以空白字符作为字段分隔符，可通过 `-F` 指定自定义分隔符，`$1` 代表第一个字段，`$0` 代表当前完整行文本。

# Linux 系统进程与定时调度指令

ps 命令用于报告当前活动进程的运行状态快照：
常用组合 `ps aux` 可展示系统全部进程的 PID、CPU 占用率、内存占用率与启动终端命令。

crontab 用于维护用户个人定时任务调度表：
标准 cron 表达式由 5 个时间字段构成，顺序依次为：分（0-59）、时（0-23）、日（1-31）、月（1-12）、周（0-7）。
星号 `*` 代表匹配任意时间，斜杠 `*/5` 代表每隔 5 个单位执行一次。
