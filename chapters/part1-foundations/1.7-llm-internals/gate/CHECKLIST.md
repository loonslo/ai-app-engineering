# L1.2 原理面试题自测清单（20 题）

在阅读 [README.md](../README.md) 详细讲解之前，先闭卷尝试在 `workbook.md` 中回答以下 20 道大模型与 AI 质量工程高频面试题，完成自我诊断后再对照核验。

### 一、Token 与分词（3 题）
- [ ] 01. 什么是 BPE（Byte Pair Encoding）分词算法？为什么大模型处理相同意思的一段中文通常比英文消耗更多 Token？
- [ ] 02. 为什么大模型 API 的计费单位是 Token 而不是字符数或单词数？
- [ ] 03. 为什么分词器的词表大小（Vocab Size）不能无限做大？

### 二、Next-Token 预测与采样参数（3 题）
- [ ] 04. 模型输出层产生的 Logits 是什么？Softmax 为什么要做数值稳定处理（减去最大值）？
- [ ] 05. Temperature 参数是如何改变预测分布的？为什么 Temperature 设为 0 时输出基本确定？
- [ ] 06. Top-p (Nucleus) 与 Top-k 采样分别是怎么截断长尾概率的？两者组合使用时的过滤顺序是什么？

### 三、上下文窗口与 KV Cache（3 题）
- [ ] 07. 为什么 Transformer 解码时需要维护 KV Cache？如果不存 KV Cache 会导致什么计算复杂度？
- [ ] 08. 给定一个 7B 模型（32 层、32 个 KV 头、Head Dim 128、FP16 存储），在 Sequence Length 为 4096 时，单条请求的 KV Cache 显存占用大约是多少？
- [ ] 09. 什么是 Prompt Caching（提示词缓存）？服务商能够成功命中缓存的前置条件是什么？

### 四、Embedding 与向量检索（2 题）
- [ ] 10. 文本 Embedding 向量的物理含义是什么？为什么向量夹角的余弦相似度能代表语义相关性？
- [ ] 11. 什么是正交向量？两个全零向量能否计算余弦相似度？为什么？

### 五、推理模型与思考 Token（2 题）
- [ ] 12. 像 DeepSeek-R1 / OpenAI o1 这样的推理模型，其内部的“思考 Token（Thinking Tokens）”是否计入 API 费用与延迟预算？
- [ ] 13. 在什么场景下（例如结构化抽取、强制工具调用），我们通常建议关闭模型的思考链或降低推理预算？

### 六、幻觉的来源与缓解（2 题）
- [ ] 14. 大模型产生事实性幻觉（Hallucination）的根本原因是什么？（从预训练概率、上下文缺失、解码策略三方面解释）
- [ ] 15. 为什么企业落地中 RAG 与“强制带引用标注（Citations）”能够有效缓解幻觉？

### 七、微调、蒸馏与量化技术区分（2 题）
- [ ] 16. 全参微调、LoRA（低秩自适应）、知识蒸馏（Distillation）、模型量化（Quantization 如 INT4/INT8）分别是在解决什么问题？
- [ ] 17. 为什么说“能用 Prompt 工程和 RAG 解决的问题，不要轻易上模型微调”？微调有哪些潜在隐患？

### 八、分类与抽取质量评估指标（3 题）
- [ ] 18. 在工单分类或敏感字段抽取中，什么是 TP、FP、FN？写出 Precision（查准率）和 Recall（查全率）的计算公式。
- [ ] 19. 为什么在涉及退款审核、高风险安全检测的场景中，我们往往更关注 Recall 而不是 Precision？
- [ ] 20. 什么是 F1-Score？在模型输出全为负样本（TP=FP=0）的极端情况下，指标应如何做除零防御？
