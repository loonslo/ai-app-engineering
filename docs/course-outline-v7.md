# AI 应用开发：模型调用、RAG 与 Agent

版本：v7 · 2026-11-05

面向有少量 Python 基础、希望转向 AI 应用开发的测试工程师与软件开发者。本版包含 **8 章、51 篇主线文章，以及 12 篇配套选修**。每节是一篇独立文章；章用于归类和安排学习顺序。

这是完整的大纲设计。下文的起始包、数据、实验、项目阶段与验收记录均为待制作内容，不表示已经实现或实测。本版承接 v6.1 的讨论，重新编排篇号；仓库现行 v3 课件及其实现状态仍按原说明理解。

## 本版的安排

课程围绕一个问题展开：怎样把模型接进软件，让它在给定资料、工具与权限范围内完成具体任务，并用样本判断效果。

提示词、结构化输出和评估提前；RAG 与上下文分别成章；Agent 先解释任务分解、工具与反馈，再引入状态图和恢复。数据库、完整登录系统、复杂前端与备份等深入实现放入配套选修。权限、人工确认、运行观察和最小部署仍在主线中。

三个案例各有用途：知识问答用于检索与引用；工单或文档抽取用于提示词、结构化输出与多模态；查询并提交服务申请用于工具、审批和执行恢复。连续项目围绕同一个内部知识助手演进，先只读，再按需增加申请草稿。报销单只作为可替换样例，不再要求读者实现完整财务系统。

原生 SDK 与普通 Python 函数承担最初的模型调用和流程。Pydantic 用于数据校验；LangGraph 在需要显式状态和恢复时引入。具体依赖与接口版本在各篇成文时锁定，不把某个框架的 API 当成课程知识结构。

## 怎样阅读和独立发布

有函数、字典、JSON 和异常处理基础即可从第 1 章开始；不熟悉这些内容时先读 E01。概念前置和运行依赖分开说明：文章可以要求理解前面的概念，但本篇所需程序、数据与运行步骤应完整提供，不要求读者拼接此前代码。

每篇的独立材料包计划包含：必要背景、输入样本、起始程序或分析模板、依赖说明、运行方式和结果记录位置。付费模型调用显式开启；离线样本和人工替身明确标注。回放可以验证控制流程，不能替代真实模型质量评估。本文中的样本数量和实验设置是教学建议，不是企业通用门槛。

标题对应一个可讨论的问题。正文可以从一次调用、一份文档或一个错误开始，按问题自然展开；不强制每篇使用同一套段落模板。代码包含必要的中文注释，代码后说明返回值怎样使用、为什么这样处理、怎样定位问题。结尾停在结果和适用范围。

每篇列出的“依据”区分主题参考、方法依据和实现参考。参考资料支持相应概念，不代表来源认可本大纲的篇数、顺序或实验结论。具体来源与适用范围见附录 D。

## 第 1 章：理解模型，完成第一次调用

先用一个小任务观察模型能做什么，以及程序需要检查什么。模型内部只讲与应用行为有关的基础，不展开训练算法推导。范围参考 Google / Kaggle 和 Microsoft 的入门课程，以及《AI Engineering》的模型基础部分。[S01][S02][S03]

### 1.1 一个需求里，哪些步骤适合交给模型

- **内容**：把“整理一条客户反馈”拆成输入、分类、字段抽取与后续处理；比较人工、规则和模型各自承担的工作，写出成功例子与暂不处理的情况。
- **独立入口**：无需模型账号；提供合成反馈、现有处理流程和一页任务说明模板。
- **实验与边界**：形成可核对的输入输出与失败去向，保留待确认问题。课程示例目标不能替代业务方要求，不预设模型一定优于规则。
- **依据**：[S03] 的应用规划与用途评估；案例和任务拆分为本课程设计。

### 1.2 调用大模型 API 时，除了回答还要读哪些字段

- **内容**：发送一次请求，查看正文、结束状态、用量与错误；介绍指令和用户输入的角色，以及预训练、指令训练与应用调用的区别。
- **独立入口**：会读函数和字典；提供最小客户端、环境变量名、脱敏响应和无账号阅读方式。
- **实验与边界**：记录一次完整响应，分别处理正常、截断和错误。字段按所选接口解释；不把一个厂商的字段名当成通用标准。
- **依据**：[S02][S03] 的模型调用与基础概念；成文时补充实际使用接口的官方说明。

### 1.3 一段文字怎样占用上下文：token、输入长度与输出预算

- **内容**：观察文字被切为 token 的结果，区分字符数、输入预算、输出预算和模型上下文上限；解释生成是逐步选择 token 的过程。
- **独立入口**：理解请求与响应；提供分词示例、长短输入和用量记录模板。
- **实验与边界**：比较不同输入的 token 数和截断情况，给输出预留空间。分词和用量以实际模型为准，不把 token 直接等同于汉字或单词。
- **依据**：[S03] 的采样与模型基础；实验用于理解限制，不推导训练过程。

### 1.4 同一个问题问几次，为什么会得到不同答案

- **内容**：用重复调用观察输出变化；解释采样参数、概率生成与事实正确性之间的区别，区分格式一致和答案正确。
- **独立入口**：提供可重复调用的脚本、固定问题和人工标注表；参数只使用所选模型实际支持的项。
- **实验与边界**：记录多次输出的差异及失败数量；低温度不承诺完全确定。少量调用只说明本次样本，不能据此排模型总榜。
- **依据**：[S03] 的采样与概率行为。

### 1.5 把一次模型响应保存下来，供本地调试使用

- **内容**：区分真实调用、录制回放和人工替身；按请求特征匹配响应，处理未知输入与模拟异常。
- **独立入口**：提供最小客户端、脱敏录制样本、合成超时和截断响应，无需在线调用即可运行。
- **实验与边界**：相同输入可重复走完相同分支，未匹配请求明确失败；不自动转成付费调用。回放验证程序行为，模型质量另行测量。
- **依据**：本课程为独立调试设计的配套方法；[S08] 支持区分运行记录与实际任务结果，不规定此录制实现。

### 1.6 给模型功能加一个能查看原始结果的小页面

- **内容**：用最小 Web 接口和原生页面调用现成函数，展示输入、回答、等待与错误；保留便于核对的请求编号。
- **独立入口**：会运行 Python；提供完整网页模板和固定响应替身，解释本例用到的 HTTP 请求。
- **实验与边界**：正常、空输入与失败都有明确反馈。仅在本机运行，身份认证和流式交互分别在后文处理。
- **依据**：[S02] 的应用与交互主题；具体页面是课程提供的工程材料。

## 第 2 章：用提示词完成单步任务

本章以工单分类、文档抽取和图片理解为例。先把单次调用做清楚，再进入工具与多步执行。范围参考 Microsoft 的提示词和应用课程，以及《AI Engineering》的提示词部分。[S02][S03]

### 2.1 写清任务、输入和输出，模型会怎样回答

- **内容**：把含糊要求改为明确的任务描述，分开指令、输入资料和输出要求，处理相互冲突的要求。
- **独立入口**：会调用模型；提供两版提示词、工单样本及相同的调用程序。
- **实验与边界**：逐条比较分类与缺失信息处理的变化，保留变差的例子。分隔符帮助表达结构，不构成权限或注入防护。
- **依据**：[S02][S03] 的提示词设计。

### 2.2 给模型几个例子，分类结果会更一致吗

- **内容**：比较无示例、典型示例与边界示例，解释少样本提示；观察示例标签、覆盖范围和排列的影响。
- **独立入口**：提供类别说明、候选示例和独立的检查样本，避免把检查答案放进提示词。
- **实验与边界**：记录每类错误及新增 token；不因少数样本改善就宣称少样本提示总是更好。
- **依据**：[S03] 的零样本与少样本提示。

### 2.3 让模型返回程序能读取的字段

- **内容**：定义字段、类型与缺失值，区分普通文本中的 JSON、接口约束输出与本地解析校验，处理拒绝和不完整响应。
- **独立入口**：提供合成工单、Schema、解析程序及成功和失败响应。
- **实验与边界**：得到可校验的候选记录或明确失败状态。结构合法不等于字段有事实依据；具体支持能力按实际接口核对。
- **依据**：[S03] 的结构化输出主题；接口实现说明在成文时按版本补齐。

### 2.4 字段格式都对，内容为什么仍然不能直接入库

- **内容**：校验日期关系、枚举值、金额合计和来源位置；把格式错误、资料矛盾与信息缺失分别处理。
- **独立入口**：提供抽取候选、原始文本、确定性校验规则和待复核记录模板。
- **实验与边界**：异常记录进入拒绝或人工复核分支，金额用明确精度处理；不让模型改数字来满足规则，也不把校验通过当成材料真实。
- **依据**：[S03] 的应用评估范围；校验规则为示例业务约定。

### 2.5 资料里没有答案时，怎样保留“不知道”

- **内容**：为缺失字段、无依据问题和冲突资料定义输出状态；比较允许空值、强制填满与要求给出证据的行为。
- **独立入口**：提供完整、缺失、矛盾三类资料，以及可回答和不可回答的问题。
- **实验与边界**：同时记录错误作答与错误拒答；自报置信度不当成可靠概率。当前只处理调用时提供的资料，检索失败在第 4 章展开。
- **依据**：[S03][S08] 的评估与失败分析；拒答规则由任务需求决定。

### 2.6 直接读取图片，还是先 OCR 再抽取

- **内容**：用同一份合成票据或表单，比较视觉模型读取与 OCR 文本抽取；检查表格对应、数字和来源位置。
- **独立入口**：提供图片、人工核对字段、预备 OCR 文本与调用骨架；在线路径需要支持图像的模型。
- **实验与边界**：比较字段正确性、无法识别项、耗时和用量。已有 OCR 文本的离线实验不算 OCR 系统验收；图片路径和文本路径分别记录。
- **依据**：[S02][S03] 的多模态应用范围；两条处理路径的对照是课程实验设计。

## 第 3 章：用样本判断应用有没有改善

把前两章积累的例子整理为评估材料，后续 RAG 和 Agent 继续沿用。评估方法参考《AI Engineering》与 Anthropic 的 Agent 评估文章；本章先从单步任务开始。[S03][S08]

### 3.1 把成功和失败例子整理成一份评估集

- **内容**：记录输入、可接受结果、依据和样本来源，区分开发样本与留出样本，检查重复、相似样本与答案泄漏。
- **独立入口**：提供合成原始反馈、标注说明及空白记录表，不要求先完成前两章。
- **实验与边界**：形成有版本的评估集，包含常见、边界和不可回答问题。教学小集用于发现问题，不声称代表真实业务分布。
- **依据**：[S03][S08] 的评估集与任务设计。

### 3.2 怎样评一个回答：程序检查、人工判断与评分规则

- **内容**：分别处理字段正确性、分类表现、证据一致性与回答可用性；写清分母、错误类别和不能自动判定的项。
- **独立入口**：提供模型输出、人工标注、程序评分器骨架和意见不一致的样本。
- **实验与边界**：生成逐条结果和分项统计；不把格式正确率当作业务准确率，不只保留一个混合总分。
- **依据**：[S03][S08] 的指标选择与评分方式。

### 3.3 平均分下降以后，先看哪一类错误

- **内容**：按信息缺失、指令歧义、字段抽错和程序处理失败归类，定位首次偏离预期的位置，再选择一个可验证的改动。
- **独立入口**：提供两次运行结果、请求配置和可回放的失败记录。
- **实验与边界**：给出错误分布、修复假设及针对性复测；后续应用再加入检索和工具失败类别，不凭最终文本猜全部原因。
- **依据**：[S04][S08] 的错误分析与迭代方法。

### 3.4 请另一个模型评分，怎样检查它是否可靠

- **内容**：制定评分说明，与人工标注比较；检查位置偏好、尺度漂移、裁判异常与不一致样本。
- **独立入口**：提供人工评过的回答对、裁判模板、交换答案顺序的运行器和离线响应。
- **实验与边界**：记录一致程度、争议样本和失效比例；裁判失败单独统计，不悄悄改用规则分数。先评裁判，再用于辅助比较。
- **依据**：[S03][S08] 的模型评分与校准。

### 3.5 同一组业务问题，怎样比较两个模型

- **内容**：在相同任务和可比配置下比较质量、延迟、费用、结构化输出支持及数据处理约束，区分单次表现和重复运行结果。
- **独立入口**：提供模型适配骨架、评估集、运行配置与空白比较表；实际候选按可访问条件选择。
- **实验与边界**：写出选择理由和失败样例，记录模型标识与日期；费用按当时价格计算，不预填赢家或承诺排名长期有效。
- **依据**：[S02][S03] 的模型比较与选择。

### 3.6 改了一段提示词，怎样知道改善了什么

- **内容**：固定样本与配置，保留提示词版本，做成对比较；区分开发集调试与留出集检查，设置重要错误的回归条件。
- **独立入口**：提供两版提示词、结果差异程序、样本及最小自动检查模板。
- **实验与边界**：输出改善、退化、无变化与失败项；自动检查只是发现回归的手段，不能用少量随机调用给出确定性效果承诺。
- **依据**：[S03][S08] 的评估迭代；具体版本与检查组织方式为课程设计。

## 第 4 章：让模型使用外部知识

先比较直接提供资料与检索，再逐项处理数据来源、切分、召回、重排、上下文和引用。每次只改一个主要环节，保留相同问题的对照。技术范围参考 Azure AI Search 的 RAG 与检索说明；本课程不要求购买 Azure 服务。[S10]

### 4.1 几份资料直接交给模型，什么时候需要 RAG

- **内容**：比较整份资料输入与先检索再生成；用小型关键词检索器建立带来源标识的最小 RAG，解释两条路径的限制。
- **独立入口**：提供几份合成制度、问题集、全文输入程序和可运行的关键词检索程序。
- **实验与边界**：记录答案、引用、输入用量和耗时，覆盖无答案问题。结论限于实际资料规模，不把向量数据库当作 RAG 的必要起点。
- **依据**：[S03][S05][S10] 的上下文与检索主题；两方案比较为本课程设计。

### 4.2 PDF 提取出的文字，为什么会丢失表格含义

- **内容**：检查页码、标题、阅读顺序、表格行列和来源标识，区分文本型 PDF 与扫描件，为后续检索保存可定位的原文。
- **独立入口**：提供可公开分发的合成 PDF、提取程序及人工核对的局部内容。
- **实验与边界**：列出提取错误和处理后的证据位置；扫描件识别仅说明入口，需要时参考 2.6，不在本篇实现完整 OCR 平台。
- **依据**：[S10] 的索引数据准备范围；解析实验与错误分类为课程设计。

### 4.3 文档应该在哪里切开：长度、标题与完整语义

- **内容**：比较固定长度与按结构切分，保留文档、版本和片段标识；观察重叠和跨段信息对检索的影响。
- **独立入口**：提供已解析文档、两种切分器、固定检索程序和有证据标注的问题。
- **实验与边界**：检查关键内容是否被拆散，并比较证据召回。向量生成与检索配置保持一致；不存在对全部文档通用的切片长度。
- **依据**：[S03][S10] 的切分与检索范围。

### 4.4 关键词不同，怎样检索意思相近的内容

- **内容**：解释 embedding、相似度与向量索引的作用，保存来源元数据；比较字面重合和语义相近的查询。
- **独立入口**：提供已切分语料、模型配置说明、小索引和检索器；允许使用明确标注的预计算向量演示。
- **实验与边界**：记录相关证据进入前 k 项的情况，检查空召回与低相关结果。更换向量模型时核对索引兼容性；相似度不直接等于事实正确概率。
- **依据**：[S01][S03][S10] 的嵌入与向量检索。

### 4.5 条款编号与自然语言问题，怎样一起检索

- **内容**：并列观察关键词和向量结果，解释混合检索与 RRF 融合；避免直接相加含义不同的原始分数。
- **独立入口**：提供双路检索程序、统一片段标识、编号查询和自然语言查询。
- **实验与边界**：比较各路与融合后的证据召回及重复片段；保留融合变差的样本，不预设混合检索一定优于单路。
- **依据**：[S10] 的混合检索与排序说明。

### 4.6 找到了相关片段，为什么仍然没有排到前面

- **内容**：对固定候选集进行 rerank，区分候选召回失败和候选排序失败，观察重排增加的延迟。
- **独立入口**：提供候选列表、相关性标注、重排器接口及离线排序样本。
- **实验与边界**：比较前列相关性和答案证据覆盖；候选里不存在的资料无法靠重排补回，实际模型收益须在线测量。
- **依据**：[S10] 的重排与相关性说明。

### 4.7 用户的问题太简略时，查询改写有没有帮助

- **内容**：比较原问题、补足指代的改写和少量子查询；保留原问题、关键实体及改写记录，限制额外查询次数。
- **独立入口**：提供简略问题、必要的上一轮信息、检索器与成对评估样本。
- **实验与边界**：检查证据召回、实体漂移与调用成本；改写失败回退原查询。这里只做有限查询变换，多步自主搜索留到 Agent。
- **依据**：[S03][S10] 的检索优化范围；查询数量和回退规则为课程实验约定。

### 4.8 检索结果怎样交给模型，并核对引用

- **内容**：去重、控制长度、保留来源标识，定义无证据与证据冲突的回答方式；分别检查引用可定位和引用是否支持回答。
- **独立入口**：提供含重复、低相关和冲突片段的候选结果、上下文拼接器与标注问题。
- **实验与边界**：生成可核对引用的回答或明确无依据状态；比较证据覆盖、答案正确性与引用支持情况。网页展示了链接不等于引用成立。
- **依据**：[S03][S05][S10] 的上下文与 RAG；位置影响的实验参考 [S09]，不照搬其历史模型结论。

### 4.9 资料更新和删除后，怎样避免继续引用旧内容

- **内容**：为文档与索引记录版本，处理增加、替换、删除和中途失败；将索引更新时间与资料生效时间分开。
- **独立入口**：提供两版合成资料、删除清单、可运行的小索引和恢复标记。
- **实验与边界**：更新后查询正确版本，删除内容不再检索到，失败续跑不重复写入。这里只处理知识索引生命周期，外部连接器见 E04，权限撤销见 7.2。
- **依据**：[S03][S10] 的数据与索引维护范围；版本规则为本课程设计。

## 第 5 章：管理对话、上下文与记忆

本章处理模型这一次能看见什么，以及哪些信息需要留到以后。上下文不是全部历史的副本，记忆也不是任务执行记录。概念参考 Anthropic 的上下文工程文章；压缩与记忆方式通过本课程样本比较。[S05]

### 5.1 用户补充一句话后，怎样接着上一轮回答

- **内容**：保存消息历史，处理指代、缺参追问、清空会话和会话隔离；说明模型请求与服务端会话记录的关系。
- **独立入口**：提供两个独立会话、完整聊天程序和无需工具的查询样例。
- **实验与边界**：补充信息能接续当前任务，切换会话不混入另一位用户的内容。客户端传来的会话编号不等于访问授权，访问控制见 7.1。
- **依据**：[S02][S05] 的聊天应用与上下文主题。

### 5.2 指令、历史和资料太多时，怎样分配上下文

- **内容**：为指令、最近消息、检索片段和工具结果分别记录来源与长度；预留输出空间，比较信息选择和排列。
- **独立入口**：提供一个完整请求构造器、超长输入和需要保留的事实清单；工具结果直接作为样本数据提供。
- **实验与边界**：检查事实保留、输入用量和回答变化；超限时有明确缩减或拒绝行为，不默默删除关键约束。
- **依据**：[S05] 的上下文选择；[S09] 支持测试信息位置的影响，效果以实际模型和任务为准。

### 5.3 对话压缩成摘要后，哪些信息可能丢失

- **内容**：比较保留最近消息与摘要加近期消息，检查实体、数字、否定条件和未完成事项，设计摘要失真时的处理方式。
- **独立入口**：提供长对话、事实核对表、两种压缩程序和模型响应样本。
- **实验与边界**：比较事实保留率、后续任务表现和 token 用量；摘要不是原始记录，保留可回查来源，不仅凭摘要流畅程度判断质量。
- **依据**：[S05] 的上下文压缩方法。

### 5.4 需要跨会话记住什么，什么时候应该忘记

- **内容**：区分偏好、已确认事实和暂时推测，设计记忆的写入条件、来源、有效期、更正与删除；读取时执行用户范围过滤。
- **独立入口**：提供两个用户的合成记录、小型记忆存储和更正、过期、删除用例。
- **实验与边界**：后续会话可使用有效记忆，纠正后不再引用旧事实，删除后不再命中。不默认保存完整对话或敏感资料。
- **依据**：[S03][S05] 的记忆主题；保留期限与确认规则由本例明确约定。

### 5.5 工具返回几千行结果，怎样只带回需要的部分

- **内容**：比较全文回填、按字段摘要和按需读取，保留结果句柄、来源与分页信息；对内容做有依据的筛选。
- **独立入口**：提供长工具结果、查询条件、上下文构造器及固定的最终问题，无需先实现完整 Agent。
- **实验与边界**：检查关键事实是否保留、额外读取次数和输入用量；不能只截取前几行并假定剩余内容无关，也不能让摘要绕过原权限。
- **依据**：[S05][S07] 的上下文与工具响应设计。

## 第 6 章：用工具与 Agent 完成多步任务

先用普通函数说明固定流程，再观察模型决定下一步时的变化。规划以可检查的步骤和实际动作表达，不要求暴露模型内部推理。控制流程参考 Anthropic 与吴恩达的公开资料；框架实现参考 LangGraph 文档。[S04][S06][S11]

### 6.1 步骤已经确定时，怎样写一个 Workflow

- **内容**：将检查输入、抽取字段和生成结果写成固定步骤，使用条件分支处理缺失和失败；说明何时需要模型动态选择步骤。
- **独立入口**：提供函数骨架、模型替身、几种工单输入，以及可阅读的 Agent 对照轨迹。
- **实验与边界**：列出各输入实际经过的路径与调用次数；初学者先完成固定流程，动态方案在 6.4 实现。固定流程同样可以调用模型。
- **依据**：[S04][S06] 的任务分解与 Workflow / Agent 区分。

### 6.2 模型提出工具调用后，Python 怎样执行

- **内容**：逐项查看工具说明、调用标识、参数校验、白名单分发、执行结果和回填消息，区分模型请求和程序授权。
- **独立入口**：提供一个只读查询函数、完整调度骨架、正常与非法调用样本。
- **实验与边界**：正常调用得到对应结果，未知工具和非法参数被拒绝；不通过动态执行任意函数名来分发，不把模型返回当成真实工具结果。
- **依据**：[S02][S06][S07] 的工具调用主题；消息格式按所选接口补充实现说明。

### 6.3 工具名称、参数和返回值，怎样影响调用选择

- **内容**：比较含糊与清楚的工具说明，调整参数边界、功能粒度、错误类型和返回字段；工具较多时按任务缩小候选范围。
- **独立入口**：提供两套工具定义、相同查询实现和包含歧义的任务样本。
- **实验与边界**：记录选错工具、缺参、重复调用与用量；候选筛选也要检查漏掉必要工具的情况。描述再清楚也不能替代运行时授权。
- **依据**：[S07] 的工具选择、命名、描述与响应设计。

### 6.4 让 Agent 根据结果决定下一步，并按时结束

- **内容**：用两个只读工具实现有限循环，记录待完成步骤、当前证据与下一动作；遇到缺参、无进展、超时或预算耗尽时结束或请求补充。
- **独立入口**：提供普通 Python 循环骨架、工具实现和正常、缺资料、重复调用的回放序列。
- **实验与边界**：比较固定流程和 Agent 的任务完成、非法动作与调用成本；检查实际动作，不将漂亮的计划文本当成完成。相同调用参数不自动等于无进展。
- **依据**：[S04][S06] 的规划和动态控制；[S08] 的轨迹与任务结果评估。

### 6.5 多检查一遍会更好吗：让 Agent 使用外部反馈

- **内容**：将规则检查、引用核对或受限测试结果反馈给生成步骤，比较一次生成与有限修订；区分自评意见和可验证反馈。
- **独立入口**：提供有缺陷的初稿、确定性检查器、修订程序和独立评估样本。
- **实验与边界**：记录修正、引入新错误、任务成功和额外成本；达到轮数上限或无改善时停止，不假定反思一定提高质量。
- **依据**：[S04] 的反思与外部反馈、[S06] 的评估与改进模式、[S08] 的任务评估。

### 6.6 把工具循环写成状态图，哪些内容应该进入状态

- **内容**：先定义消息、候选动作、工具结果、错误和终止状态，再分别说明节点职责、边条件、更新规则和失败分支，用 LangGraph 实现相同流程。
- **独立入口**：提供普通循环基线、状态定义、完整工具替身和状态转换样例。
- **实验与边界**：对照两种实现的输入输出，验证成功、工具失败和超限路径。框架整理控制流程，不自动改善模型决策；长期记忆与图状态分开管理。
- **依据**：[S11] 的状态图能力；采用时机参考 [S06]，具体状态结构为课程设计。

### 6.7 程序重启后，怎样继续未完成的任务

- **内容**：引入任务标识、持久化检查点和恢复入口，区分已记录结果与待执行动作；在工具前后分别制造中断。
- **独立入口**：提供可运行状态图、本地持久化配置及中断位置选择器，工具保持只读。
- **实验与边界**：重启后检查主路径、失败路径和恢复路径，标出可能重复执行的位置。检查点不能保证外部写操作只发生一次，写操作见 7.5。
- **依据**：[S11] 的持久化与恢复；本篇不展开分布式执行平台。

## 第 7 章：让 AI 操作受到明确约束

本章使用两类材料：不同用户可访问的知识，以及需要确认的申请草稿。身份解析、授权、工具执行与模型生成分别承担职责。安全主题参考 Microsoft 课程；Agent 工具权限与人工介入参考 Anthropic 和 LangGraph 文档。[S02][S06][S11]

### 7.1 不同用户问同一个问题，怎样只检索各自能看的资料

- **内容**：将可信身份交给服务端授权层，把权限约束用于检索、原文访问与工具查询；分别检查文档标题、片段和最终回答。
- **独立入口**：提供预置身份适配器、两租户数据和查询服务；无需先搭完整登录系统。
- **实验与边界**：跨租户、猜文档标识和越权工具请求均有拒绝结果。演示身份只用于本地，真实部署前必须接入可信认证；实现配套见 E03。
- **依据**：[S02][S10] 的安全与受限检索范围；租户样例和负例为课程设计。

### 7.2 权限撤销后，缓存答案和历史引用怎样处理

- **内容**：识别检索缓存、答案缓存、历史会话与原文访问中的权限状态，设计失效和读取时复核。
- **独立入口**：提供已登录用户、撤权事件、缓存答案和历史会话的完整小程序。
- **实验与边界**：撤权后的新请求、历史查看和引用打开按新权限处理；已经发送给用户的内容无法由服务端撤回，实验记录这项边界。
- **依据**：[S02][S10] 的权限主题；撤权场景是本课程针对数据生命周期增加的设计。

### 7.3 文档里出现“忽略规则”，程序会怎样处理

- **内容**：区分用户请求、系统指令、检索资料和工具结果的信任来源；限制工具权限与数据外发，检查资料内指令是否影响动作。
- **独立入口**：提供合成注入文档、假工具、输出接收器和允许操作清单，不访问真实外部目标。
- **实验与边界**：同时验证答案污染和未授权动作；提示词约束与程序授权分层检查。通过这些样例不意味着已经证明抵御所有提示词注入。
- **依据**：[S03] 的防御性提示词与 [S06] 的工具控制主题；攻击样本为本课程自建。

### 7.4 Agent 准备提交申请时，怎样让人确认具体内容

- **内容**：生成可检查的申请草稿，保存待确认版本；展示字段、目标与影响，确认后校验批准内容与执行内容一致。
- **独立入口**：提供带暂停点的流程、两份不同版本草稿、批准与拒绝入口以及假提交服务。
- **实验与边界**：批准、拒绝、过期和内容被修改都走明确分支；执行前再次核对授权。点击确认不等于提交成功，也不自动允许后续任意动作。
- **依据**：[S06][S11] 的人工介入；批准版本绑定与业务授权由课程示例明确实现。

### 7.5 提交超时后，怎样避免重复操作

- **内容**：为外部写操作建立幂等标识和状态记录，区分未执行、已成功与结果未知；通过查询状态或人工处理解决不确定结果。
- **独立入口**：提供可模拟“已提交但响应丢失”的接口、执行记录和重复请求样本。
- **实验与边界**：检查重试和恢复后是否产生重复申请，结果未知时不盲目重做；不宣称在任意外部系统上实现严格只执行一次。
- **依据**：[S11] 的恢复能力提供实现背景；幂等与核对是外部接口约定，示例不扩展为支付系统。

## 第 8 章：交付应用，观察和改进运行结果

本章保留与 AI 功能直接相关的运行问题，使用完整的小服务作为起始包。生产架构主题参考《AI Engineering》，运行后反馈与评估结合参考 Anthropic。[S03][S08] 部署和发布方法是课程工程设计，不表示已经获得生产验收。

### 8.1 一次回答很慢或答错，怎样沿调用记录定位

- **内容**：把请求、检索、重排、模型与工具调用关联起来，记录耗时、状态、配置版本和受控的证据标识；区分事件和原始内容。
- **独立入口**：提供完整小服务、几份故障记录与本地追踪查看器，不要求先购买观察平台。
- **实验与边界**：定位第一次异常或主要耗时，验证修复假设；默认不写凭据、完整票据和敏感正文，调试采样另有明确范围。
- **依据**：[S03] 的应用观察主题；[S08] 对轨迹与实际结果的区分。

### 8.2 一次任务花了多少费用，哪里可以减少调用

- **内容**：记录模型、输入输出用量、重复调用和任务成功；分别试验上下文缩减、缓存或简单模型路由，检查质量是否变化。
- **独立入口**：提供调用明细、可配置价格表、权限与版本明确的缓存样例和评估集。
- **实验与边界**：计算每次任务及每个成功任务的成本，包含失败与重试；价格注明日期。应用答案缓存与厂商提示词缓存分开记录，不跨权限复用答案。
- **依据**：[S03] 的成本、路由与缓存主题；实验一次只改变一种主要策略。

### 8.3 模型服务限流或超时后，怎样重试和降级

- **内容**：区分配置错误、限流、暂时失败和超时，设置有上限的重试、等待与并发控制；备用模型按能力与数据范围检查。
- **独立入口**：提供故障注入客户端、批量请求、备用模型替身和明确的预算配置。
- **实验与边界**：观察请求数量、最终状态和预算上限；参数或认证错误不持续重试，备用模型能力不足时明确失败。写操作继续遵循 7.5。
- **依据**：[S03] 的应用运行架构范围；具体重试条件在成文时核对服务商规范。

### 8.4 回答边生成边显示时，“停止”应该停止什么

- **内容**：定义文本、工具进度、错误与结束事件，用简单页面显示流式响应；传播取消请求，并区分已显示内容和已完成结果。
- **独立入口**：提供原生页面、SSE 服务和可控的流式替身，不要求 React 基础。
- **实验与边界**：检查正常结束、用户取消、断连和工具失败；浏览器关闭不自动代表上游停止计费，不能取消已完成的外部操作。
- **依据**：[S02] 的 AI 交互主题；事件与取消实现为课程工程设计。

### 8.5 任务超过一次请求的时间，怎样继续执行和查看

- **内容**：分开接收请求、执行任务和读取状态；持久化任务标识、状态及事件序号，刷新页面后继续读取已有进度。
- **独立入口**：提供最小持久化任务服务、后台工作进程、进度页面与模拟长任务。
- **实验与边界**：验证刷新、进程重启、重复接收和取消；任务状态与模型会话分开存储。演示只覆盖单机可恢复执行，队列规模化另行选型。
- **依据**：[S03][S11] 提供应用架构与恢复背景；任务服务组织方式为课程设计。

### 8.6 把 AI 服务交给另一台机器运行

- **内容**：固定依赖和模型配置，区分配置、密钥、知识数据与运行状态，提供启动检查、健康检查和最小测试环境部署步骤。
- **独立入口**：提供完整小应用、合成语料、环境变量清单和部署模板；具体平台在实施时选定并补充官方文档。
- **实验与边界**：在另一环境启动并记录问答、权限、失败返回与停服结果；对外开放前接入真实身份控制。只有本地成功时，结果只写本地验证。
- **依据**：[S01][S03] 的生产管理与应用架构主题；不是某云厂商的指定部署方案。

### 8.7 新版本发布以后，怎样检查退化并处理用户反馈

- **内容**：关联代码、提示词、模型配置、索引和评估集版本；检查发布前回归，观察有限试用，保留回退条件和反馈复现材料。
- **独立入口**：提供两版小服务、稳定评估集、反馈表和发布记录模板；默认使用合成反馈演练。
- **实验与边界**：演练一次退化发现、停止发布和恢复，确认版本兼容；真实试用另记日期与条件。试用反馈进入开发样本前做必要清理，留出集避免反复调参污染。
- **依据**：[S03][S08] 的反馈与持续评估；发布演练和回退要求由本课程明确约定。

- **独立入口**：需要基本 HTTP 知识；提供本地测试身份服务、应用模板与合成用户，不使用真实企业凭据。
- **实验与边界**：检查有效、过期、签发者不符和权限不足请求；具体令牌校验依所用组件和协议实施，演示配置不能直接当生产配置。

### E04 外部知识接口变化后，同步任务怎样继续

- **内容**：用适配层处理返回结构、分页、限流和错误，记录增量游标与删除事件，设计失败续跑。
- **独立入口**：提供两版合成上游接口、同步程序、数据变更和故障脚本；下游使用现成索引写入函数。
- **实验与边界**：验证重复页、删除、字段变化和中断后的结果；上游没有可靠删除通知时明确补偿核对方法，不宣称实时一致。
- **依据**：[S10] 的多来源数据接入范围；连接器与同步机制为课程工程设计。

### E05 数据库增加字段后，新旧服务怎样共存

- **内容**：围绕一次具体字段变更设计兼容读写、迁移与回退，区分可回退代码和不可直接回退的数据操作。
- **独立入口**：提供旧版数据、两版服务、迁移脚本骨架和备份检查方法。
- **实验与边界**：验证历史记录、新写入和回退后的读取；仅在可丢弃副本演练，不把清空重建作为迁移验收。
- **依据**：通用发布配套，与 8.7 衔接；成文时补充具体数据库及迁移工具官方资料。

### E06 状态图升级后，昨天暂停的任务怎样继续

- **内容**：检查节点名称、状态字段和暂停位置变化，选择兼容、显式迁移或继续运行旧版本的方案。
- **独立入口**：提供两版图、旧检查点和暂停任务，不需要读者自行积累旧数据。
- **实验与边界**：逐个恢复历史任务，检查状态与动作；无法兼容时给出明确处理路径，不用新任务成功证明旧任务兼容。
- **依据**：[S11] 的持久化及向后兼容资料；节点与状态迁移方案按所用版本核对。

### E07 并发增加以后，怎样测出 AI 服务的承受范围

- **内容**：区分服务排队、模型限流与下游瓶颈，记录吞吐、延迟分布、错误和成本；比较不同并发上限。
- **独立入口**：提供完整小服务、固定延迟替身、合成请求与负载脚本；真实模型测试单独开启并设预算。
- **实验与边界**：得到当前条件下的容量记录及过载行为；替身测试不能证明真实供应商配额或模型吞吐，报告分开写。
- **依据**：[S03] 提供推理与运行优化范围；负载方案为课程工程设计。

### E08 有了备份文件，怎样确认服务真的能恢复

- **内容**：区分原始知识、可重建索引、任务状态和业务记录，在隔离位置恢复并验证相互对应关系。
- **独立入口**：提供合成数据、备份样本、小服务、恢复清单和预期记录。
- **实验与边界**：实际恢复后执行查询和暂停任务检查，记录耗时与可能丢失范围；备份存在不算恢复成功，具体目标由使用方确认。
- **依据**：持久化应用的工程配套；存储恢复命令以实施时选择的官方文档为准。

### E09 把一个 Python 查询函数提供给 MCP 客户端

- **内容**：解释 host、client、server 的职责，以及工具发现、参数说明、执行和返回；用本地传输封装一个只读函数。
- **独立入口**：理解工具调用；提供函数、服务端与客户端模板及合成数据，固定协议和 SDK 版本。
- **实验与边界**：完成发现和调用，比较直接函数调用与协议调用的责任边界；MCP 不替代模型决策或应用授权。
- **依据**：[S12] 的协议架构；[S07] 的工具设计。

### E10 MCP 工具放到远程以后，谁可以调用它

- **内容**：围绕 HTTP 传输设置授权流程和资源访问范围，检查客户端、授权服务、MCP 服务与业务后端的身份关系。
- **独立入口**：需要基础 HTTP 与授权知识；提供受限远程测试服务、测试客户端和权限样例，所有凭据在本地配置。
- **实验与边界**：检查未授权、过期和越权调用；本地 stdio 的运行身份不照搬为 HTTP 授权方案，也不把传输授权等同于全部业务权限。
- **依据**：[S12] 的 HTTP 授权规范；成文时记录所用规范与实现版本。

### E11 把任务交给多个 Agent，实际增加了什么

- **内容**：将同一份资料整理任务分别交给单 Agent 与有明确分工的多个 Agent，限制通信内容、权限、预算和终止条件。
- **独立入口**：提供两种完整程序、相同资料和任务集，以及相同或明确记录差异的资源预算。
- **实验与边界**：比较任务成功、证据遗漏、协调错误和成本；只有在实验支持时才选复杂方案。共享记忆和工具不自动共享权限。
- **依据**：[S04][S06] 的协作模式；评价方式参考 [S08]。

### E12 提示词和 RAG 仍不够时，怎样判断是否需要微调

- **内容**：区分缺知识、缺指令、稳定行为偏差与数据问题；整理训练、开发和测试材料，设计小规模微调与原模型的对照。
- **独立入口**：提供有版本的合成分类或格式转换数据、现有提示词方案和实验记录模板；训练实施需另选支持条件与预算。
- **实验与边界**：先完成是否值得训练的分析；选做一轮小规模训练与留出集评估，记录泄漏与退化。微调不作为频繁更新事实或处理权限的替代方式，不涉及预训练大模型。
- **依据**：[S02][S03] 的微调适用性、数据与模型适配主题。

### 模块与状态分别保存什么

| 模块 | 职责和持有状态 | 不交给它决定的事项 |
|---|---|---|
| 请求入口与身份适配 | 校验输入，解析可信身份，产生请求标识 | 不接受模型生成的用户身份作为授权依据 |
| 检索与知识管理 | 维护文档、版本、片段、索引和权限过滤 | 不用模型提示词代替资料访问控制 |
| 上下文与记忆 | 选择本次可见信息，管理已确认且有来源的记忆 | 不把对话摘要当成业务执行账本 |
| 模型客户端 | 组织请求、解析响应、记录用量和失败 | 不直接执行模型输出中的任意代码或函数名 |
| 流程与任务状态 | 管理当前步骤、预算、暂停、终止和检查点 | 不以检查点存在推断外部动作已经成功 |
| 工具执行与业务记录 | 校验权限和参数，保存批准版本、幂等标识与执行结果 | 不因模型再次请求就自动重复写入 |
| 评估与运行记录 | 保留版本、样本、轨迹与结果，分析错误和变化 | 不把离线替身结果登记为真实模型或生产结果 |

这张表描述职责，不要求把小项目拆成多个服务。起步可以使用一个进程和少量模块，状态和权限的含义仍需清楚。

## 附录 C：每篇成文前的准备与核对

### 独立发表需要具备的材料

1. 开头交代读者正在处理什么输入、想得到什么结果，以及本篇默认的知识基础。
2. 起始包可单独取得；包括本篇需要的程序、合成或获准使用的数据、依赖、配置变量名和运行步骤。分析类文章提供完整案例与空白模板即可。
3. 一个主要实验或可核对的分析结果。可以有辅助步骤，但不要把多个完整系统塞进一篇文章。
4. 明确观察哪些输出、怎样判断失败，以及结论适用的模型、数据和环境。真实调用、回放、替身分开标注。
5. 参考资料紧邻相关结论；引用论文时注明任务和模型范围，引用官方文档时记录版本或核对日期。正文代码接口在写作时再查官方说明。
6. 文章正文完成后检查语气、中文注释、结果解释和来源；图片只在能帮助理解时使用，不为统一版式强行增加。

这些是编辑准备项，不要求正文逐条照着排版。前文链接用于解释概念，本篇代码和背景仍需完整。涉及多个可独立判断的问题时再拆篇，不为了凑数量拆成短片段。

### 企业应用范围怎样判断

| 应用范围 | 课程中应实际验证的内容 | 不能由目录本身证明的事项 |
|---|---|---|
| 文本分类与抽取 | 字段与业务校验、代表性样本、失败处理、质量/费用记录、可部署服务 | 真实数据分布下的长期效果、特定组织的数据处理要求 |
| 受限知识问答 | 来源、版本、检索与答案质量、引用、权限、撤权、无依据处理 | 所有企业数据源的接入、所有文档格式和权限系统的兼容 |
| 带动作的助手 | 工具授权、参数校验、预算、人工确认、幂等、不确定结果与恢复 | 任意外部系统的事务保证、无人监督的高影响操作安全 |
| 测试环境交付 | 版本、运行记录、配置、部署、回退、交接与一次反馈修复 | 生产 SLA、真实容量、灾难恢复目标及组织级验收 |

课程可以准备这些能力，实际企业项目仍需根据任务和环境补充验证。未安排大模型预训练、GPU 推理集群、完整财务平台、全面前端开发、行业专属合规方案；需要相应能力时另设专题。

提示词、RAG 和微调的判断可以先看失败类型：指令和示例不足，先在第 2—3 章比较；缺少外部事实或需要频繁更新资料，检查第 4 章；已经有稳定数据和可重复的行为偏差，再进入 E12。它们可以组合使用，选择仍由对照实验决定。
