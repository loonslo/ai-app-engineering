# SQLite 体系架构概述

SQLite 是一个进程内的小型轻量关系型数据库引擎，由前端编译器、中端虚拟机与底层存储引擎组织构成。
在典型嵌入式场景中，SQLite 直接读写单一磁盘文件，无需独立后台守护服务运行。

# 存储引擎与事务机制

B-Tree 引擎负责组织管理所有数据表与索引页。
寻呼机 Pager 位于 B-Tree 之下，提供强一致事务 ACID 保证与 WAL（Write-Ahead Logging）预写日志机制。
WAL 模式下允许多个只读并发事务与一个读写事务同时运行而不相互阻塞。

# 核心组件与功能职责

| 组件 | 层次 | 核心职责 |
| :--- | :--- | :--- |
| SQL 编译器 | 前端 | 词法分析、语法解析与生成执行代码计划 |
| 虚拟机 VDBE | 中端 | 执行 SQL 编译器生成的底层字节码指令 |
| B-Tree 引擎 | 后端 | 组织和维护页面、搜索树与数据持久结构 |
| 寻呼机 Pager | 底层 | 提供磁盘页面读写缓存、事务原子性与 WAL 日志控制 |
| OS 适配层 | 系统 | 统一封装不同操作系统平台的文件锁与 I/O 接口 |
